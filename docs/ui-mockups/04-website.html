Our north star

A self-governing, self-sustaining organization that stewards humanity's collective intelligence and rewards every idea for what it makes possible.

Every contribution is an idea in an open graph. When new work builds on old work, credit and value flow back to it.

How it works

1 · Ideas

Papers, data, code and reviews are ideas, each linked to the ideas it builds on.

2 · Open review

Work is checked in the open and reviewed by paid, fairly chosen reviewers, and ratings keep changing as results are reproduced.

3 · Value flows back

Value that reaches an idea flows back to the work that made it possible, so foundations are rewarded.
