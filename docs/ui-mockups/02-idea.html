LoRA: Low-Rank Adaptation of Large Language Models

Edward J. Hu, Yelong Shen, Phillip Wallis, Zeyuan Allen-Zhu, Yuanzhi Li, Shean Wang, Lu Wang, Weizhu Chen

arXiv:2106.09685 License: see source work sha256:[first 12 hex]

Summary

Freezes the weights of a pretrained model and trains small low-rank update matrices inside each layer, cutting the number of trainable parameters for fine-tuning by orders of magnitude while matching full fine-tuning quality.

What does LoRA build on?

Mainly on the finding that fine-tuning changes have a low intrinsic dimension, which motivates training only a low-rank update. It positions itself against adapters, which add inference latency, and against prefix-tuning, which uses up sequence length. Its experiments use Transformer models up to GPT-3.
